# 可复现评测说明

本项目中的性能和准确率数字只有在满足本文件要求后，才可以用于 README、简历或面试陈述。

## 评测指标

| 指标 | 定义 | 必须保留的证据 |
|---|---|---|
| 官网发现成功率 | 正确官网数 / 测试竞品数 | 竞品清单、期望官网、实际官网 |
| 功能字段准确率 | 与人工标注一致的功能判断 / 已评估判断 | 标注表、来源页面、程序输出 |
| 定价字段准确率 | 正确套餐与价格字段 / 已评估字段 | 官方定价页、标注表、程序输出 |
| 来源覆盖率 | 至少有一个有效 URL 的重要字段 / 重要字段总数 | 报告证据清单 |
| 端到端成功率 | 成功生成可读报告的任务 / 总任务数 | 每次运行状态与错误日志 |
| 分析耗时 | 从任务开始到报告生成 | 原始开始/结束时间 |
| 并行加速比 | 串行耗时 / 并行耗时 | 同一输入、同一环境的两组记录 |

## 最小测试集

- 至少 10 个产品，覆盖结构简单官网、动态页面、重定向和反爬页面。
- 每个产品至少人工核验官网、核心功能页和定价页。
- 测试失败也必须保留，不能只统计成功样本。
- 记录日期、Python版本、模型、地区、并发度和网络环境。
