## 一、项目概述

### 1.1 产品定位

基于大语言模型(LLM)的多Agent协作系统，自动化完成竞品分析任务，为产品经理、市场分析师和创业者提供快速、全面的竞品洞察。

### 1.2 产品愿景

"让竞品分析从3天缩短到30分钟"

### 1.3 目标用户

| 用户类型 | 核心需求 | 使用频率 |
|---------|---------|---------|
| 产品经理 | 快速了解竞品功能差异 | 每周2-3次 |
| 市场分析师 | 生成系统化竞品报告 | 每周1-2次 |
| 创业者 | 立项前市场调研 | 每月1-2次 |
| 投资人 | 评估创业公司竞争力 | 每月若干次 |

### 1.4 核心价值

- **自动化**: 减少80%的手动信息收集工作
- **全面性**: 覆盖功能、定价、口碑等多维度
- **智能化**: AI生成深度洞察和可操作建议
- **可追踪**: 支持定期监控和变化预警

### 4.2 Agent详细设计

#### 4.2.1 Coordinator Agent

**职责**:
- 理解用户输入意图
- 制定分析计划
- 协调其他Agent执行
- 处理异常和重试
- 汇总最终结果

**输入**:
```json
{
  "user_query": "分析Notion和Obsidian的核心功能",
  "competitors": ["Notion", "Obsidian"],
  "analysis_dimensions": ["features", "pricing"],
  "output_format": "markdown"
}
```

**输出**:
```json
{
  "status": "success",
  "report_path": "/reports/20240630_notion_vs_obsidian.md",
  "execution_time": 245,
  "agents_used": ["crawler", "analyzer", "reporter"]
}
```

**状态机设计**:
```
[START] → [UNDERSTAND_INTENT] → [CREATE_PLAN] 
   ↓                                    ↓
[ERROR] ← ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ [EXECUTE_PLAN]
                                        ↓
                              ┌─────────┴─────────┐
                              ↓                   ↓
                        [CRAWLER_RUNNING]   [ANALYZER_RUNNING]
                              ↓                   ↓
                        [CRAWLER_DONE]     [ANALYZER_DONE]
                              └─────────┬─────────┘
                                        ↓
                                 [REPORTER_RUNNING]
                                        ↓
                                 [REPORTER_DONE]
                                        ↓
                                   [END]
```

#### 4.2.2 Data Collection Agent

**职责**:
- 爬取竞品官网
- 提取结构化数据
- 清洗和验证数据
- 存储到向量数据库

**爬取策略**:
```python
爬取页面优先级:
  1. 首页 (提取核心功能)
  2. /features 或 /product (详细功能)
  3. /pricing 或 /plans (定价信息)
  4. /docs 或 /help (功能文档)
  
每个页面的处理逻辑:
  1. 下载HTML
  2. 提取文本内容
  3. 调用LLM提取结构化信息
  4. 验证和清洗
  5. 存储
```

**输出数据结构**:
```json
{
  "competitor_name": "Notion",
  "website": "https://www.notion.so",
  "crawled_at": "2026-06-30T19:00:00Z",
  "data": {
    "features": {
      "core": ["文档编辑", "数据库", "看板视图"],
      "advanced": ["API接口", "模板市场"]
    },
    "pricing": {
      "plans": [
        {"name": "Free", "price": 0},
        {"name": "Plus", "price": 10, "period": "month"}
      ]
    },
    "company_info": {
      "founded": "2016",
      "hq": "San Francisco"
    }
  },
  "raw_content": "..."
}
```

#### 4.2.3 Analysis Agent

**职责**:
- 功能对比分析
- 定价策略分析
- 生成AI洞察
- 计算相似度

**分析维度**:

1. **功能对比矩阵**
```python
输入: [竞品A的功能列表, 竞品B的功能列表, ...]
处理:
  1. 功能标准化 (统一命名)
  2. 功能分类 (核心/增值)
  3. 生成对比表
输出: DataFrame (功能 × 竞品)
```

2. **定价分析**
```python
输入: [竞品A的定价数据, 竞品B的定价数据]
处理:
  1. 定价模式识别 (订阅/一次性/免费增值)
  2. 价格区间对比
  3. 功能价值分析 (哪个套餐最划算)
输出: 定价分析报告
```

3. **AI洞察生成**
```python
Prompt模板:
"""
你是一位资深的产品战略顾问。
请基于以下竞品对比数据，生成3-5条有价值的商业洞察。

数据:
{feature_comparison}
{pricing_analysis}

要求:
1. 指出差异化定位
2. 分析各自优劣势
3. 给出战略建议

输出JSON格式。
"""
```

## 七、数据设计

### 7.1 数据模型

#### Competitor (竞品)
```python
class Competitor:
    id: str                  # UUID
    name: str                # 竞品名称
    website: str             # 官网URL
    created_at: datetime     # 创建时间
    updated_at: datetime     # 更新时间
    
    # 爬取的数据
    features: List[Feature]  # 功能列表
    pricing: PricingPlan     # 定价信息
    company_info: Dict       # 公司信息
    
    # 元数据
    crawl_status: str        # 爬取状态
    last_crawled: datetime   # 最后爬取时间
```

#### Feature (功能)
```python
class Feature:
    id: str
    name: str                # 功能名称
    category: str            # 分类 (核心/增值)
    description: str         # 描述
    supported: bool          # 是否支持
    confidence: float        # 置信度 (0-1)
```

#### AnalysisReport (分析报告)
```python
class AnalysisReport:
    id: str
    competitor_ids: List[str]  # 分析的竞品
    created_at: datetime       # 生成时间
    
    # 分析结果
    feature_matrix: DataFrame  # 功能对比矩阵
    pricing_analysis: Dict     # 定价分析
    insights: List[str]        # AI洞察
    
    # 报告
    markdown_content: str      # Markdown内容
    html_content: str          # HTML内容
    charts: List[str]          # 图表路径
```
