## 产品定义与需求拆解
针对日常竞品分析"耗时久、标准化程度低"的业务痛点，主导该工具从 0 到 1 落地。完成需求定义与功能优先级排序，输出完整功能模块地图；基于 Streamlit 设计 Web 端交互原型，落地「新建分析 / 分析结果 / 向量搜索 / 历史记录」四大功能模块——支持自然语言输入、爬取进度可视化、功能对比矩阵与定价/版本/洞察的结构化展示，以及相似竞品检索与历史报告回看。

## AI 策略与架构设计
采用 Multi-Agent 架构将复杂任务拆解为协调、爬虫、分析、报告四大专用 Agent，基于 LangGraph 的 StateGraph 编排节点式工作流，以状态机管控执行顺序并支持失败重试。提示词工程方面，为每个 Agent 设计结构化 System Prompt（任务描述 + 输出格式约束 + Few-shot 示例）；针对爬虫 Agent 加入"无法确认的信息输出 null 而非猜测"的硬约束作为 Bad Case 调优手段；输出层引入 JSON Schema 强制校验与自动修复，降低下游解析异常。数据采集层接入 RAG 思路，将竞品结构化数据存入轻量向量库（零外部模型下载），分析相似竞品时检索历史结论作为上下文注入各分析 Agent 的 Prompt。建立效果测评机制，通过 Demo 模式生成报告后人工核验功能对比矩阵准确率，并反向迭代 Prompt 模板与解析逻辑。技术选型上综合评估 LangGraph / AutoGen / CrewAI 后选定 LangGraph；支持 OpenAI 与 DeepSeek 多模型接入以控制成本（抽取类低温、生成类较高温）。最终端到端打通"自然语言输入 → 结构化报告"流程：用户自然语言输入后，系统在分钟级生成包含功能对比矩阵、定价分析、版本更新追踪与 AI 洞察的结构化报告；内置 12 类主流产品识别（笔记 / 设计 / 项目管理等），并可经检索扩展至任意品类，同时提供无需 API Key 的演示模式与可量化的官网发现成功率 / 功能矩阵准确率评测脚本。
